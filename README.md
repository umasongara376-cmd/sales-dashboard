# Sales Dashboard

An Excel-based sales dashboard project that includes a workbook and a screenshot preview for exploring sales information.

## Repository Contents

- `sales_dashboard.xlsx` — the Excel workbook containing the dashboard and its supporting sheets.
- `dashboard image.png` — a visual preview of the dashboard.

## Getting Started

1. Clone or download this repository.
2. Open `sales_dashboard.xlsx` in Microsoft Excel or a compatible spreadsheet application.
3. Review the worksheets, formulas, charts, tables, and any filters included in the workbook.
4. If the workbook uses external data connections, configure the correct source before refreshing.

## Project Overview

The dashboard is intended to support visual review of sales data. The specific KPIs, reporting period, categories, and findings should be verified in the workbook; this README does not assume metrics that have not been documented.

## Requirements

- Microsoft Excel or a compatible spreadsheet application.

## Reproducibility Notes

For a stronger portfolio presentation, document the dataset source, KPI definitions, any data-cleaning steps, and a few insights confirmed from the workbook. Keep a separate copy before changing formulas or source data.
